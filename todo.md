### Rebrand-blocking
- [ ] **TLS certificate for the local HTTPS server** — `index.js` runs an HTTPS server on port 3001 using a checked-in cert (`privkey1.pem`/`fullchain1.pem`) for `mymachine.openbuilds.com`, a domain you don't own. That cert already expired 2025-02-24, so it's currently non-functional either way. Figure out what depends on that secure-context HTTPS server (likely camera/webcam access, which browsers require HTTPS for) and decide: get your own domain + cert, or find another way to provide a secure context, before shipping the rebrand.
- [ ] **Full rebrand pass — sweep every "OpenBuilds" reference and swap in ConcatCNC.** Bigger than it sounds because not every "OpenBuilds" mention is actually about *this app's identity* — some point to real, distinct, still-relevant OpenBuilds services this fork keeps depending on for hardware support. Needs judgment per hit, not a blind find/replace. Known buckets so far:
  - **This app's own identity — replace:** `package.json` (`name`, `appId: "openbuilds.control"`, `productName: "OpenBuildsCONTROL"`, `description`, `repository` — still points at the old OpenBuilds-CONTROL GitHub repo instead of ConcatCNC), window title strings in `index.js` (the GPU-info debug window title, the jog window title, the tray context menu's "Quit OpenBuilds CONTROL..." label at [index.js:3123](index.js#L3123) — note there are *two* nearly-identical "Quit OpenBuilds CONTROL..." labels, one already partly addressed via the balloon text fix on 2026-08-30, the other in the macOS dock menu still needs it), `<title>` tags and visible text in `app/index.html`, `README.md`/`CONTRIBUTING.md`/`CODE_OF_CONDUCT.md`/`SECURITY.md`, `build/licence.txt`, NSIS installer strings.
  - **Real external OpenBuilds resources — probably keep, but confirm with the user each time:** `cam.openbuilds.com` (a genuinely separate product, OpenBuilds CAM, that this app launches for G-code generation), `docs.openbuilds.com` (actual documentation for OpenBuilds hardware/controllers this app still talks to, e.g. Blackbox/GrblHAL boards), `openbuildspartstore.com` (real storefront for the physical hardware, relevant if ConcatCNC still targets OpenBuilds machines), the `app/img/openbuilds.svg`/`openbuilds.png` icons used specifically on the "OpenBuilds CAM" menu button (correctly identifies that third-party integration, not this app), and the `.obc` file association labeled "OpenBuilds CAM Project" (a real third-party file format, not this app's branding).
  - **Needs a case-by-case call:** the `openforum` button linking to an old forum thread about *this software specifically* (probably should go/point elsewhere now that it's a separate fork), and anything in `CONTRIBUTING.md`/`CODE_OF_CONDUCT.md`/`SECURITY.md` that points at OpenBuilds' own Discord/forum/security contact as the support channel — decide whether ConcatCNC needs its own equivalents or should drop those sections.
  - **Don't touch:** historical entries in `CHANGELOG.txt` — that's a record of what actually happened under the old name, not something to rewrite.
  AGPL-3.0 lets you keep the code; the "OpenBuilds" name/trademark is separate and shouldn't carry over for the parts that are actually this app's own identity.

### Lower priority / just noted
- [ ] **Large binaries baked into git history** — pushing to ConcatCNC surfaced several old `dist/win-unpacked`/`dist/linux-ia32-unpacked` build artifacts (multiple `app.asar` files up to ~86MB, a ~75MB Linux binary) already committed in the fork's history, even though `dist/` is gitignored going forward. They don't block pushes/clones, just bloat them. Fixing this properly means rewriting git history (`git filter-repo` or similar) and force-pushing — deliberately left undone since that's invasive and worth doing on purpose, not as a side effect of a cleanup pass.
- [ ] **Duplicate Font Awesome 5 bundles** — `app/lib/fontawesome5/` and `app/lib/furcanIconPicker/fontawesome-5.11.2/` both ship a full Font Awesome 5 icon set. Both are actually loaded (one for the main UI, one is a dependency of the icon-picker widget used in macros), so this isn't dead code — just shipped twice. Could investigate whether the icon picker can be pointed at the already-loaded copy to shave install size, but that's a "nice to have," not a bug.
